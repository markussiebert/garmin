# Garmin Connect IQ Data Fields

A collection of custom data field apps for Garmin Edge cycling computers.

## Apps

### [Daily Driver](daily-driver/)

A full-screen data field for everyday riding on the **Garmin Edge 1030 Plus**. All essential ride metrics at a glance with Strava-inspired zone visualization.

**Features:**
- Speed gauge with logarithmic scale — instantly see if you're above/below target avg speed
- Power & HR zone bars with Strava-style color gradients (purple/red)
- Active zone highlighting with smooth tapered transitions
- Bar markers: triangle (current), line (Norm. Power / Avg HR), star (FTP/LT)
- 10 key metrics: Power, HR, Avg Power, Avg HR, Norm. Power, Cadence, Distance, Elevation, Ride Time, Time of Day
- Full light/dark mode support

[Full documentation](daily-driver/README.md)
